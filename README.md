# بوابة وصلة للمعامل

نموذج Frontend فقط لبوابة معمل الأسنان، بواجهة عربية RTL وبيانات محلية. يغطي الـMVP:

- لوحة متابعة التشغيل اليومي والتنبيهات.
- استقبال الطلبات ومراجعة ملفات الحالة وتسعيرها.
- إدارة مراحل التصميم والتصنيع وفحص الجودة.
- محادثات مرتبطة برقم الحالة ومرفقاتها.
- الفواتير والدفعات والأرصدة المتبقية.
- مهام الاستلام والتوصيل وتأكيد التسليم.
- إعدادات المعمل والخدمات والفريق والإشعارات.

## التشغيل

```bash
npm install
npm run dev
```

كل البيانات تجريبية وتُحفظ محليًا في المتصفح. لا يوجد باك اند أو دفع أو تخزين ملفات حقيقي في هذه النسخة.
