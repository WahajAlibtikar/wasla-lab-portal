# بوابة وصلة للمعامل

نموذج Frontend فقط لبوابة معمل الأسنان. يركز الإصدار الحالي على استقبال طلبات الأطباء، مراجعة ملفات الحالة، طلب التوضيح، حفظ مسودة عرض السعر وقبول الطلب.

## التشغيل

```bash
npm install
npm run dev
```

كل البيانات تجريبية وتُحفظ محليًا في المتصفح. لا يوجد باك اند أو دفع أو تخزين ملفات حقيقي في هذه النسخة.
