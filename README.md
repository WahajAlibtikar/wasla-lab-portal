# بوابة وصلة للمعامل

نموذج Frontend فقط لبوابة معمل الأسنان، بواجهة عربية RTL وبيانات محلية. يغطي الـMVP:

- لوحة متابعة التشغيل اليومي والتنبيهات.
- استقبال الطلبات ومراجعة ملفات الحالة وتسعيرها.
- إدارة مراحل التصميم والتصنيع وفحص الجودة.
- محادثات مرتبطة برقم الحالة ومرفقاتها.
- الفواتير والدفعات والأرصدة المتبقية.
- مهام الاستلام والتوصيل وتأكيد التسليم.
- إعدادات المعمل والخدمات والفريق والإشعارات.

## التشغيل

```bash
npm install
npm run dev
```

كل البيانات الظاهرة في الواجهة ما زالت تجريبية وتُحفظ محليًا في المتصفح، لذلك لم تتغير طريقة تشغيل نموذج الويب الحالي.

## قاعدة البيانات المشتركة

أضيفت بنية PostgreSQL/Supabase جاهزة لتكون المصدر المشترك لبوابة المعمل وتطبيق الطبيب القادم. تشمل migrations للجداول والعلاقات وRLS والتخزين الخاص وRealtime، مع بيانات تجريبية لدليل المعامل.

راجع [هندسة قاعدة البيانات](docs/database-architecture.md) قبل ربط الواجهات أو تطبيق migrations على مشروع سحابي.
